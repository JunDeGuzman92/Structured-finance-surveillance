# Structured Finance Data Quality & Surveillance Platform

An end-to-end structured finance data platform for ingesting,
validating, reconciling, and analyzing asset-level ABS regulatory data.

## Initial Asset Class

Auto Loan Asset-Backed Securities (Auto ABS)

## Initial Data Source

U.S. SEC EDGAR ABS-EE asset-level regulatory filings.

## Technology Stack

- Python
- SQL
- DuckDB
- Parquet
- Polars / Pandas
- SEC EDGAR
- Streamlit
- Git / GitHub

## Project Status

Under active development.
